  تحديث أور پاي AurPay — 4.zip
  (إصلاح ثبات البيانات على Vercel + قاعدة بيانات دائمة)

ماذا كان يحدث ولماذا؟

  المشاكل الثلاث التي لاحظتها سببها واحد: على Vercel كل «نسخة»
  من الخادم تحتفظ بذاكرتها المنفصلة:

  1) تسوي حساب جديد ← ينضاف لذاكرة نسخة (A) فقط. أول طلب يصل
     لنسخة ثانية (B) ما يعرف الحساب ← يرد 401 ← الواجهة تخرجك
     تلقائيًا للشاشة الرئيسية، والحساب «يختفي».

  2) التحويل اليدوي مرحلتان (طلب ← تأكيد بـ PIN). الطلب يُنشأ
     على نسخة، والتأكيد يصل لنسخة ثانية ما تعرفه ← يرد
     «طلب التحويل غير موجود» ← ترجع بدون خصم.

  3) حوالة ١٧٠ ألف كانت فقط بذاكرة نسخة واحدة. بعد إعادة
     تدويرها انمحت، ولما سددت طلب الـ١٧ ألف صار آخر سجل لهالشخص
     بمبلغ ١٧ ألف — فبان لك أنو «الفاتورة تغيرت».

ماذا يصلح 4.zip؟

  ✚ قاعدة بيانات مشتركة دائمة (Turso — مجاني بلا بطاقة):
    كل نسخة تحمّل أحدث حالة وكل عملية (تسجيل/تحويل/دفع/محادثة)
    تُحفَظ فورًا للجميع. الحسابات والتحويلات تبقى للأبد.

  ✚ حماية إضافية: تسجيل الدخول وتأكيد التحويل يسحبان أحدث
    حالة من القاعدة المشتركة قبل الرد بـ«غير موجود».

  ✚ /api/health يعرض وضع القاعدة:
       {"db":{"mode":"turso"}}  ← شغالة
       {"db":{"mode":"memory"}} ← ما ضبطت المتغيرات

  ✚ ملفات قفل جديدة (bun.lock + package-lock.json) تطابق
    package.json الجديد (أضاف @libsql/client) حتى ما يفشل
    التنصيب على Vercel مثل ما صار سابقًا.

───────────────
خطوات التطبيق
───────────────

1) فك ضغط 4.zip داخل مجلد المشروع (نفس مستوى package.json)
   واختر «استبدال / Replace» لكل الملفات.

2) ارفع التحديث:

       git add -A
       git commit -m "fix: persistent shared DB (Turso) + lockfiles"
       git push origin main

3) من Vercel: Deployments ← آخر صف ← قائمة ⋯ ← Redeploy.

───────────────
تشغيل قاعدة البيانات الدائمة (مرة واحدة — دقيقتين)
───────────────

  بدون هذي الخطوة التطبيق يشتغل مثل قبل (ذاكرة تجريبية)،
  لكن المشاكل الثلاث تبقى موجودة على Vercel!

  1) ادخل turso.tech وسجّل بحساب GitHub (مجاني تمامًا).
  2) Create Database ← سمها aurpay ← اختر أقرب منطقة.
  3) من صفحة القاعدة انسخ الرابط (يبدأ بـ libsql://...).
  4) Settings ← API Tokens ← Generate token ← انسخه.
  5) في Vercel: Settings ← Environment Variables ← أضف:

       TURSO_DATABASE_URL = libsql://aurpay-xxxx.turso.io
       TURSO_AUTH_TOKEN  = eyJ...

     (اختر Production ثم Add لكل واحد)

  6) Deployments ← ⋯ ← Redeploy.

  7) افتح رابط موقعك + /api/health — لازم تشوف:

       "db": { "mode": "turso" }

     إذا شفت "memory" راجع الخطوة 5 (المتغيرات) ثم Redeploy.

  بعد هاي الخطوة: كل حساب جديد يظل موجود، كل تحويل يخصم
  فعليًا ويثبت، وكل الفواتير والسجلات تبقى دائمة ✔

───────────────
للتشغيل المحلي
───────────────

       npm install
       npm run dev

  (اختياري) قاعدة محلية بملف:
       set TURSO_DATABASE_URL=file:./db/aurpay.db
       npm run dev
