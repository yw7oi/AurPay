  تحديث أور پاي AurPay — إصلاح فشل بناء Vercel (3.zip)
════════════════════════════════════════════════════════════

سبب الفشل الأرجح عندك:

  عند استبدال 2.zip تغيّر ملف package.json (حذفنا prisma وغيّرنا
  التبعيات)، لكن مستودعك احتفظ بملف bun.lock القديم الذي ما عاد
  يطابقه. Vercel يختار Bun للتنصيب بسبب وجود bun.lock، وينصّب
  بوضع «القفل المجمد» (frozen) — أي عدم تطابق = فشل خطوة
  Installing dependencies = فشل البناء كله.

ماذا يصلح 3.zip؟

  1) يرفع bun.lock جديد مطابق تمامًا + package-lock.json (لـ npm)
     — أيّ مدير حزم يختاره Vercel سينجح.
  2) يثبّت الإصدارات المُختبرة بالضبط: Next 16.1.3 + React 19.2.3.
  3) يستبدل الملفات القديمة المُعرّضة للمشاكل بنسخ نظيفة تلقائيًا
     (البروكسي القديم ← 404، db.ts ← ملف فارغ، مشغّل بايثون ← 404)
     — ما تحتاج تشغّل أي سكربت تنظيف.
  4) يرفع سقف زمن دوال المساعد الذكي إلى 60 ثانية (حد Vercel
     المجاني) حتى ما تنقطع الردود الطويلة.

───────────────
خطوات التطبيق
───────────────

1) فك ضغط 3.zip داخل مجلد المشروع (نفس مستوى package.json)
   واختر «استبدال / Replace» لكل الملفات.

2) ارفع التحديث:

       git add -A
       git commit -m "fix: Vercel build (fresh lockfiles + stubs)"
       git push origin main

3) من Vercel: Deployments ← آخر صف ← قائمة ⋯ ← Redeploy.

4) للتشغيل المحلي بعد التحديث:

       npm install
       npm run dev

───────────────
إذا فشل مرة أخرى
───────────────

  افتح الرابط الفاشل في Vercel ← اضغط على Deployment الفاشل ←
  اضغط "Building" ← انسخ نص الخطأ (آخر ٣٠ سطر تقريبًا) وأرسله
  لي وسأصلحه فورًا. الرسالة الحقيقية تكون داخل السجل وليست في
  العنوان العام "Build Fail".
