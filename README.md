## 🚀 النشر على Vercel (٣ خطوات)

</div>

1. **ارفع المشروع إلى GitHub** (انسخ محتويات هذا المجلد — تأكد أن `.env.example` موجود و`.env` غير موجود).
2. من [vercel.com/new](https://vercel.com/new) → **Import** المستودع. Vercel يكتشف Next.js تلقائيًا — لا تغيّر أي إعدادات بناء.
3. (اختياري لكن مُوصى به) أضف متغيرات البيئة من الجدول أدناه ثم اضغط **Deploy**.

> **بدون أي مفاتيح** التطبيق يشتغل 100% — المساعد الذكي يتحول تلقائيًا إلى محرك النوايا العربي المدمج (deterministic engine).
> **مع مفاتيح Groq المجانية** تحصل على الوكيل الذكي الكامل: محادثة طبيعية + استدعاء أدوات + إدخال صوتي.

## 🗄️ قاعدة بيانات دائمة على Vercel (موصى به بشدة — دقيقتان)

</div>

<div dir="rtl">

بدون قاعدة بيانات، كل «نسخة» (instance) على Vercel تحتفظ بذاكرتها الخاصة: الحسابات الجديدة والتحويلات **تختفي** عند إعادة تدوير النسخة، وتسجيل الدخول يردك للشاشة الرئيسية. مع **Turso** (مجاني بلا بطاقة) تشترك كل النسخ بقاعدة واحدة وتبقى البيانات للأبد:

1. سجّل بحساب GitHub على **[turso.tech](https://turso.tech)**
2. أنشئ قاعدة بيانات (مثل `aurpay`) وانسخ رابطها (`libsql://…turso.io`)
3. أنشئ **API Token** (Settings ← Tokens) وانسخه
4. في Vercel: **Settings ← Environment Variables** أضف:
   - `TURSO_DATABASE_URL` = رابط القاعدة
   - `TURSO_AUTH_TOKEN` = التوكن
5. **Redeploy** ← افتح `/api/health` وتأكد من `"db": { "mode": "turso" }`

</div>

> محليًا يشتغل بنفس الكود مع ملف: `TURSO_DATABASE_URL=file:./db/aurpay.db`
> بدون أي من هذي المتغيرات يعمل التطبيق بوضع الذاكرة التجريبي كما قبل.

## 🔑 متغيرات البيئة (كلها اختيارية)

</div>

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `TURSO_DATABASE_URL` | رابط قاعدة Turso الدائمة — **يثبّت الحسابات والتحويلات عبر كل النسخ** | — |
| `TURSO_AUTH_TOKEN` | توكن Turso | — |
| `URPAY_JWT_SECRET` | سرّ ثابت لجلسات الدخول (حدده مرة قبل مشاركة الموقع) | افتراضي ديمو |
| `GROQ_API_KEY_1` … `GROQ_API_KEY_5` | مفاتيح [Groq](https://console.groq.com/keys) المجانية — حتى ٥ مفاتيح في مجمّع يدور تلقائيًا عند 429 | — |
| `GROQ_API_KEYS` | بديل: قائمة مفاتيح مفصولة بفواصل | — |
| `URPAY_AGENT_MODEL` | موديل الوكيل | `openai/gpt-oss-120b` |
| `URPAY_ASR_MODEL` | موديل تحويل الصوت لنص | `whisper-large-v3` |
| `GROQ_BASE_URL` | عنوان Groq المتوافق | `https://api.groq.com/openai/v1` |
| `URPAY_BRIDGE_SECRET` | سرّ داخلي لمسارات `/api/internal/*` | `urpay-bridge-secret` |
| `URPAY_SYNC_TTL_MS` | كل كم ملي ثانية تُزامَن النسخة مع القاعدة المشتركة | `15000` |

## 💻 التشغيل محليًا

</div>

```bash
# افتح http://localhost:3000
```

## 🧠 هرم تدرّج المساعد الذكي (ماذا يحدث عند فشل أي مزوّد؟)

</div>

| الترتيب | المزوّد | متى يُستخدم | عند فشله |
|---|---|---|---|
| 1 | **Groq** `gpt-oss-120b` مع استدعاء أدوات أصلي | عند توفر `GROQ_API_KEY_*` | مفتاح يصطدم بـ 429 → يبرد ~دقيقة و**المفتاح التالي يخدم فورًا**؛ فشل كامل → التالي |
| 2 | **z-ai bridge** | داخل بيئة Z.ai فقط | → التالي |
| 3 | **محرك النوايا العربي المدمج** | دائمًا متاح، بلا إنترنت | — (لا يفشل أبدًا) |

نفس المنطق للإدخال الصوتي: Groq Whisper (بنفس المفاتيح) ثم z-ai ثم رسالة عربية ودّية.

```
└─ المزامنة: src/lib/urpay-server/persist.ts — مرآة صفوف Turso/libSQL: كل كتابة تُحفَظ فورًا وكل نسخة تحمّل أحدث حالة
```

## ⚠️ ملاحظات مهمة (اقرأها قبل العرض)

</div>

1. **قاعدة البيانات الدائمة**: بدون `TURSO_DATABASE_URL` يعمل التطبيق بوضع الذاكرة التجريبي — كل نسخة على Vercel تبدأ بحالة نظيفة. **مع Turso** تبقى كل الحسابات والتحويلات والفواتير للأبد عبر كل النسخ.
2. **المجدول الذكي** (الدفع التلقائي المجدول) يعمل بشكل كسول عند كل طلب — لا يحتاج cron خارجي.
3. **الحماية من الدفع المزدوج** خمس طبقات (قفل ذري + فحص حالة + معرّف طلب + TTL ٢٤ ساعة + مصادقة) — راجع `src/lib/urpay-server/transfer.ts` و `bills/pay/route.ts`.
4. **إدخال الصوت** على Vercel يحتاج مفاتيح Groq (Whisper). بدونها تظهر رسالة عربية واضحة.
