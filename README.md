# أور پاي — AurPay 🇮🇶

**محفظة عراقية ذكية بمساعد AI يدفع فواتيرك ويحوّل أموالك من محادثة واحدة.**

## ⚡ يشغل مباشرة — لا يحتاج باكند خارجي

هذا الإصدار **مبني بالكامل على Next.js** — الواجهة + الـ API + قاعدة بيانات في الذاكرة (in-memory) في مشروع واحد. لا Python، لا خادم منفصل، لا إعدادات إضافية. ارفعه على Vercel وسيشتغل فورًا.

## 🧠 هرم تدرّج المساعد الذكي (ماذا يحدث عند فشل أي مزوّد؟)

</div>

| الترتيب | المزوّد | متى يُستخدم | عند فشله |
|---|---|---|---|
| 1 | **Groq** `gpt-oss-120b` مع استدعاء أدوات أصلي | عند توفر `GROQ_API_KEY_*` | مفتاح يصطدم بـ 429 → يبرد ~دقيقة و**المفتاح التالي يخدم فورًا**؛ فشل كامل → التالي |
| 2 | **z-ai bridge** | داخل بيئة Z.ai فقط | → التالي |
| 3 | **محرك النوايا العربي المدمج** | دائمًا متاح، بلا إنترنت | — (لا يفشل أبدًا) |

نفس المنطق للإدخال الصوتي: Groq Whisper (بنفس المفاتيح) ثم z-ai ثم رسالة عربية ودّية.

## ✨ الميزات

</div>

- 💬 **مساعد ذكي عربي** — «دفع فاتورة زين»، «حوّل ٥٠ ألف لزينب»، «شكد صرفت هالشهر؟» — مع تأكيد PIN للعمليات الحساسة
- 📋 **دفع فواتير**: كهرباء، ماء، إنترنت، اتصالات، صحة، تعليم، غاز — مع فواتير مُنشأة ذكيًا حسب مدينتك
- 🔄 **تحويلات بطورين** (طلب → قبول → تنفيذ) مع QR وإلغاء تلقائي بعد ٢٤ ساعة
- 🎯 **أهداف توفير** + **ميزانيات شهرية** بتنبيهات عبور الحد
- ⏰ **دفع مجدول** (إيقاف/استئناف/تعديل/إلغاء)
- 🔐 قفل تدريجي للـ PIN (٤→٣→٢→١ محاولة ثم إيقاف ٣ دقائق)
- 📊 تحليلات، إشعارات، تصدير CSV/PDF، وضع ليلي، عربي/إنجليزي
